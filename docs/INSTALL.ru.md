# Установка с нуля — без опыта разработки

[English](INSTALL.en.md) · [Возможности приложения](../README.ru.md)

Вы установите неофициальное приложение непосредственно на свой Homey Pro. Установки одним нажатием через Homey App Store пока нет. На первый раз выделите примерно 20–40 минут. Терминал — это окно для ввода команд: ниже их достаточно копировать, писать программу не нужно.

## 1. Что понадобится

- **Anker A2345**, уже подключённая к Wi-Fi и работающая в родном приложении Anker. Проверьте номер модели на корпусе: похожие зарядки не считаются совместимыми автоматически.
- Homey Pro с прошивкой **13.5.0 или новее**. Версию можно посмотреть в системной информации Homey. Выпуск проверен на Homey Pro (2023).
- Аккаунт Homey с правом установки приложений на нужный Homey.
- Собственные email/пароль Anker, регион и страна аккаунта. Это не логин Homey.
- Компьютер Windows или macOS с интернетом. Проще всего подключить его к обычной домашней сети, где находится Homey; гостевую сеть лучше не использовать.

Одного Homey Bridge или Homey Cloud недостаточно. Платный аккаунт GitHub, Git, Docker, SSH и ключ разработчика не нужны. После установки компьютер можно выключить.

## 2. Установите Node.js

Откройте [официальную страницу Node.js](https://nodejs.org/en/download), выберите **LTS версии 24 или новее**, скачайте и запустите установщик для своей системы. Оставьте компонент npm включённым. После установки откройте новое окно терминала.

Как открыть терминал:

- **Windows:** в меню «Пуск» найдите **Командная строка / Command Prompt**. Этот вариант позволяет избежать проблемы с политикой запуска `npm.ps1` в PowerShell.
- **macOS:** нажмите Command–Пробел, найдите **Терминал / Terminal** и откройте его.

Выполните по одной команде, нажимая Enter после каждой:

```sh
node --version
npm --version
```

Обе должны вывести номера версий. Версия Node должна начинаться с `v24` или более нового основного номера. Если команда не найдена, завершите/повторите установку Node.js и откройте новое окно терминала.

## 3. Скачайте и распакуйте приложение

1. Откройте [последний релиз GitHub](https://github.com/edsallo/homey-anker-prime/releases/latest).
2. В разделе **Assets** скачайте **Source code (zip)**. Установочный архив `.tar.gz` для этой инструкции не нужен.
3. Распакуйте ZIP: в Windows — **Извлечь всё**, в macOS — двойной щелчок по архиву.
4. Откройте полученную папку. В правильной папке должны лежать **app.json**, **package.json**, **package-lock.json** и папка **scripts**. Если внутри только ещё одна папка, откройте её.

Не запускайте команды прямо из окна просмотра ZIP. Для скачивания публичного релиза вход в GitHub не требуется.

## 4. Откройте терминал в папке приложения

**Windows:** откройте распакованную папку проекта в Проводнике, нажмите адресную строку, введите `cmd` и нажмите Enter. Командная строка откроется в этой папке.

**macOS:** в Терминале введите `cd ` — с пробелом после cd. Перетащите папку проекта из Finder в окно Терминала и нажмите Enter. Перетаскивайте папку, а не файл app.json.

Проверьте содержимое:

- Windows: команда `dir`.
- macOS: команда `ls`.

В списке должны быть `app.json` и `package.json`. Если их нет, сначала перейдите в нужную папку.

## 5. Скачайте необходимые инструменты

```sh
npm ci
```

Дождитесь возвращения обычной строки ввода. Команда скачивает закреплённые версии зависимостей, включая официальный Homey CLI, в папку проекта. Это может занять несколько минут. Пароль Anker здесь не требуется, на Homey пока ничего не устанавливается.

Предупреждения об устаревших пакетах или аудите инструментов разработки сами по себе не означают ошибку установки. Сообщение `npm ERR!` / `npm error` нужно проверить. Не используйте `npm audit fix --force`: эта команда может заменить проверенные версии инструментов.

## 6. Войдите в Homey и выберите нужный хаб

```sh
npm run homey -- login
```

Официальный CLI откроет авторизацию в браузере. Введите данные **Homey/Athom**, не Anker. Если браузер не открылся, следуйте адресу/инструкции, показанным в терминале. После завершения авторизации вернитесь к терминалу.

Затем выполните:

```sh
npm run homey -- select
```

Выберите свой Homey Pro стрелками и нажмите Enter, когда появится список. Если у вас несколько Homey, внимательно проверьте выбранное имя: приложение установится именно туда.

## 7. Установите приложение на Homey

```sh
npm run install:homey
```

Утилита соберёт, проверит и загрузит приложение. Дождитесь сообщения **Installed Anker 0.1.8** либо номера скачанной версии. Теперь терминал можно закрыть: приложение работает на Homey, компьютер ему больше не нужен.

Помощник использует загрузку из буфера: обычная команда CLI в проверенной конфигурации выдавала `Missing File`. Существующие устройства и данные подключения сохраняются. Используется авторизация из предыдущего шага — вручную копировать токен Homey не требуется.

Для знакомых с CLI стандартная альтернатива — `npm run homey -- app install`. Для постоянной установки не используйте `app run` и не добавляйте `--clean`: последний параметр удаляет существующие данные приложения. Разница между install и run описана в [официальной документации Homey](https://apps.developer.homey.app/the-basics/getting-started/homey-cli).

## 8. Добавьте зарядку в приложении Homey на телефоне

1. Откройте **Устройства → + / Добавить устройство**.
2. Найдите **Anker → Prime 250W · A2345**.
3. Выберите регион аккаунта Anker: **Europe** или **Global**, и двухбуквенный код страны аккаунта. Форма по умолчанию предлагает Europe/DE; измените их, если ваш аккаунт относится к другому региону/стране. Язык телефона не определяет регион аккаунта.
4. Введите **собственные email и пароль Anker** в форме Homey. Не редактируйте код и не вводите их в терминал.
5. Выберите найденную зарядку, назначьте комнату/зону и завершите добавление.
6. Подождите появления свежих показаний. В карточке можно выбрать режим зарядки или порт; на вкладке показаний будут общая мощность и Вт/В/А выбранного порта.

Если A2345 не найдена, убедитесь, что она видна в Anker под тем же аккаунтом, затем проверьте регион и страну. Успешная авторизация Homey не заменяет вход в Anker.

## 9. Отдельные порты и расширенные настройки

Для отдельных плиток повторите **Добавить устройство → Anker → USB-порты (дополнительно)**. Выберите нужные C1–C4 или A1+A2. Второй раз входить в Anker не нужно. A1 и A2 управляются вместе; основную зарядку оставьте добавленной.

Через шестерёнку основной карточки → **Расширенные настройки** доступны яркость, девять штатных заставок, тайм-аут экрана, энкодер, приоритеты USB-C, формат и расписание часов. Сохраните изменения и дождитесь подтверждения. Режим зарядки и выбор порта уже находятся в самой карточке и здесь не дублируются.

Виджет **Anker Prime** добавляется отдельно через редактирование домашнего экрана/Dashboard Homey. Для работы карточки устройства и отдельных портов он не обязателен.

## Обновление, восстановление и удаление

**Обновление:** скачайте ZIP нового релиза, распакуйте в новую папку и откройте там терминал. Выполните `npm ci`, проверьте выбранный Homey командой `npm run homey -- select`, затем `npm run install:homey`. Повторный вход нужен, только если его запросит CLI. Не удаляйте старое приложение и не используйте `--clean`: одинаковый ID позволяет обновить приложение с сохранением устройств и настроек. Обновления с GitHub ручные, не автоматические через App Store.

**Сменили пароль Anker:** откройте настройки основной зарядки и восстановление/повторное подключение, введите новые данные. Удалять все устройства ради смены пароля не нужно.

**Удаление:** удалите Anker через список приложений Homey. Это удаляет интеграцию и может повлиять на устройства и Flow, но не сбрасывает саму зарядку к заводским настройкам. Удаление скачанной папки с компьютера не удаляет приложение с Homey. Перед удалением инструментов можно выйти из локального CLI командой `npm run homey -- logout`.

## Если что-то не получилось

| Симптом | Что проверить |
|---|---|
| Не найдены node / npm | Установите Node.js вместе с npm и откройте новый терминал. |
| PowerShell запрещает запуск скриптов | Используйте Командную строку либо `npm.cmd` вместо `npm`. Не отключайте защиту системы целиком. |
| ENOENT / не найден package.json | Неверная папка или архив не распакован. Найдите папку с package.json. |
| EACCES / отказано в доступе | Распакуйте в обычную пользовательскую папку, например «Загрузки», не в системный каталог. Глобальная установка npm и sudo здесь не нужны. |
| Истекла авторизация / не выбран Homey | Повторите login, затем select из шага 6. |
| Missing File | Используйте включённый помощник: `npm run install:homey`. |
| Нет связи с Homey | Проверьте питание, выбранный хаб и сеть; исключите гостевую сеть. |
| Приложение сразу не появилось | Перезапустите мобильное приложение Homey, проверьте список приложений и успешное завершение установки. |
| Зарядка недоступна / нет подтверждения команды | Проверьте интернет и связь Anker, дождитесь свежих данных и уточните фактическое состояние перед повтором. |
| Карточка после обновления выглядит по-старому | Закройте и откройте карточку; при необходимости перезапустите мобильное приложение Homey. |
| Вт не равны произведению В × А | Это отдельные показания зарядки с её частотой измерений и округлением; приложение не заменяет их расчётом. |

Если нужна помощь, [создайте issue](https://github.com/edsallo/homey-anker-prime/issues): ОС, версии Node, Homey и приложения, текст ошибки. Удалите из текста и снимков пароли, email, серийные номера, токены. Не прикладывайте приватный файл аккаунта приложения или файл авторизации CLI.

Установщик проверен на macOS. Инструкции Windows пока не проверены на физическом Windows-компьютере. Официальные материалы: [первые шаги Homey](https://apps.developer.homey.app/the-basics/getting-started), [Homey CLI](https://apps.developer.homey.app/the-basics/getting-started/homey-cli), [Node.js](https://nodejs.org/en/download).
