# Anker Prime для Homey Pro

[English](README.md) · **[Установка с нуля](docs/INSTALL.ru.md)** · [English installation guide](docs/INSTALL.en.md) · [Релизы](https://github.com/edsallo/homey-anker-prime/releases)

Неофициальное приложение для настольной зарядки **Anker Prime 250W, 6 портов, модель A2345**. Показывает параметры USB-портов, позволяет управлять питанием и менять настройки через Homey.

<img src="drivers/prime/assets/images/large.png" alt="Зарядное устройство Anker Prime A2345" width="240">

**Версия 0.1.8 — экспериментальный выпуск сообщества.** Публикация на GitHub не означает наличие в Homey App Store. Требуются интернет и облако Anker; автономного управления по локальной сети в этой версии нет.

## Совместимость

| Компонент | Поддержка |
|---|---|
| Зарядка | Только Anker Prime **A2345** |
| Homey | Homey Pro с прошивкой **13.5.0 или новее** |
| Проверенное оборудование | Homey Pro (2023), Homey 13.5.0; A2345 с прошивкой 2.1.1.6 |
| Другие аппаратные версии Homey Pro | Отдельно не проверялись |

| Аккаунт | Зарядка уже добавлена в Anker на iPhone/Android; вход по email и паролю |
| Регионы | Europe и Global; аппаратно проверен Europe |
| Языки | Русский и английский |

## Компактная карточка зарядки

В основной карточке находятся штатные переключатели Homey: **режим зарядки** и **выбор порта**. Выберите C1, C2, C3, C4, A1 или A2. На вкладке показаний отображаются:

- Общая мощность USB.
- Текущий режим зарядки.
- Выбранный порт и его подпись, если она задана.
- Мощность, напряжение и ток выбранного порта — отдельными числовыми показателями.

Выбор порта меняет только отображение, а не питание. Он общий для всех пользователей этой карточки Homey.

Все 18 исходных измерений портов продолжают обновляться отдельно, хотя скрыты из основного обзора. Они доступны для истории Insights и Flow. У трёх показателей выбранного порта отключены история и теги: переключение между портами не смешивает их графики.

**Мощность USB — не потребление из розетки.** Приложение не учитывает потери преобразования, энергию из электросети и накопленную энергию USB.

## Отдельные устройства портов

После добавления основной зарядки можно добавить **Anker → USB-порты (дополнительно)** и выбрать только нужные:

| Устройство | Управление и данные |
|---|---|
| C1, C2, C3, C4 | Включение/выключение, мощность, напряжение, ток |
| A1 + A2 | Общее питание, суммарная мощность, отдельные мощность/напряжение/ток A1 и A2 |

A1 и A2 измеряются отдельно, но управляются одной физической группой. При использовании дополнительных портов оставьте основную зарядку добавленной в Homey. Плитки можно назвать «Ноутбук» или «Телефон на столе».

## Расширенные настройки основной карточки

Откройте зарядку → шестерёнка/настройки → **Расширенные настройки**. Названия пунктов меню могут различаться между версиями мобильного приложения Homey.

| Раздел | Возможности |
|---|---|
| Названия портов | Локальные подписи Homey для C1–C4, A1 и A2 |
| Дисплей | Яркость 20–100% с шагом 5%; скринсейвер; время выключения экрана |
| Выключение экрана | Никогда, через 30 секунд, 1, 5 или 30 минут |
| Управление | Прямое/обратное направление энкодера; приоритет до двух USB-C |
| Часы и расписание | 12/24 часа; начало и окончание показа часов; каждый день недели; режим выходных Anker |

Доступны девять штатных заставок: **Celestial, Robotic, Lunar, Galactic, Meteorite, Floral Waltz, Impressionist Bloom, Sweet Treats, Rhythmic Hue**. При применении актуальные адрес загрузки и контрольная сумма запрашиваются у Anker. Пункт «Другой / из Anker» сохраняет заставку вне этого каталога, а не загружает новое изображение.

Значения синхронизируются с зарядкой, включая изменения в родном приложении и Flow. Время расписания соответствует часам зарядки. При сохранении отправляются команды с ожиданием подтверждения. Если сохранение нескольких параметров завершилось ошибкой, часть изменений уже могла примениться: перед повтором проверьте актуальные значения.

Режим зарядки и выбор порта остаются в основной карточке и не дублируются в расширенных настройках.

## Виджет — по желанию

Виджет **Anker Prime** можно добавить на домашний экран или Dashboard Homey. Это отдельный интерфейс, не основная карточка устройства.

В нём есть обзор шести портов, общая мощность, Вт/В/А, пять переключателей питания, подписи, короткий график текущего сеанса просмотра, быстрые и произвольные таймеры отключения, недельные расписания включения/выключения портов. Раздел режима и экрана содержит настройки режима, яркости, тайм-аута, формата часов, энкодера и приоритета USB-C.

Таймер: до 1435 минут с шагом 5 минут; 0 отменяет его. События включения и выключения расписания сохраняются отдельно. Для A1+A2 таймер и расписание общие. График виджета временный, для долговременной истории используйте Insights. Компоновка виджета проверена в браузере; полная проверка виджета на iPhone ещё не проведена.

## Flow и Advanced Flow

Основная зарядка предоставляет **13 собственных карточек**:

| Раздел | Карточки |
|---|---|
| Когда — 3 | Изменилось питание порта (теги порта и состояния); изменился режим зарядки; изменилось состояние связи |
| И — 1 | Питание указанного порта включено / выключено |
| Тогда — 9 | Питание порта; таймер отключения; режим зарядки; яркость; тайм-аут экрана; формат часов; направление энкодера; приоритет USB-C; событие расписания порта |

Порт в условии выбирается внутри самой Flow-карточки и не зависит от переключателя отображения основной карточки. Для управления доступны C1–C4 и общая группа A. Режимы: AI Power, приоритет подключения, два ноутбука, малая мощность. В расписаниях Flow доступны ежедневно, будни, выходные или отдельный день; произвольные комбинации задаются в виджете.

Дополнительные устройства портов используют штатные возможности Homey для питания и измерений. Числовые теги скрытых измерений доступны для логики и сравнений; у показателей выбранного порта теги специально отключены.

Примеры: уменьшать яркость ночью, выключать нужный порт по времени, уведомлять о потере связи. Отдельного определения «зарядка завершена» и карточки «мощность ниже X в течение Y минут» нет — для этого нужна собственная логика Flow и таймеры.

## Установка

**Если вы никогда не устанавливали приложения для разработки, начните с [подробной инструкции](docs/INSTALL.ru.md).** Программировать не нужно. Git, Docker и постоянно включённый компьютер не требуются. Компьютер понадобится для первой установки и последующих обновлений.

Для опытных пользователей, из распакованной папки проекта:

```sh
npm ci
npm run homey -- login
npm run homey -- select
npm run install:homey
```

Установщик собирает приложение закреплённой версией официального Homey CLI и загружает его через авторизованное соединение CLI. Загрузка из буфера обходит ошибку `Missing File`, встреченную при разработке. Добавленные устройства и данные подключения сохраняются. После установки терминал можно закрыть — приложение работает на Homey.

Для установки используется аккаунт Homey. **Логин и пароль Anker вводятся позже в окне добавления устройства Homey**, не в терминале или исходниках.

## Что проверено и какие есть ограничения

На оборудовании проверены: вход и обнаружение Anker, данные всех шести портов, восстановление после перезапуска приложения, выбор отображаемого порта, обнаружение дополнительных портов, изменение яркости, штатной заставки, тайм-аута дисплея, направления энкодера, формата часов, расписания часов и режима выходных. После тестов исходные значения восстановлены. Яркость также проверена через Flow.

Реализованы, но не прошли полную аппаратную проверку: отключение занятых портов, смена режима зарядки, приоритет USB-C, таймеры и расписания питания портов. Десять автоматических тестов проверяют авторизацию, пакеты, повреждённые данные, параметры команд, подтверждения и очередь. Проверка Homey уровня `publish` пройдена; это не сертификация App Store.

Пока отсутствуют: создание/выбор пользовательских профилей из Homey, настройка протоколов зарядки профиля, загрузка собственных скринсейверов, обновление прошивки, синхронизация подписей портов с облаком Anker, автономное LAN-управление и расчёт накопленной энергии USB. Активный пользовательский профиль отображается, а выбирать его нужно в Anker. Защиты зарядки и настройки прошивки не обходятся.

API Anker неофициальный и может измениться. При потере связи или свежих данных устройство становится недоступным. Команда считается успешной только после подтверждения состояния зарядкой.

## Аккаунт и конфиденциальность

Каждый пользователь вводит свой аккаунт Anker при добавлении устройства. Email, пароль и сессия хранятся в приватном `/userdata` приложения на Homey с правами файла 0600. Они не помещаются в настройки устройства, ответы виджета или репозиторий. Пароль нужен для обновления истёкшей сессии; **дополнительного шифрования файла самим приложением нет**. После удаления последнего устройства аккаунта его запись удаляется. После смены пароля Anker используйте восстановление подключения основной зарядки.

Авторизация и каталог используют HTTPS Anker, данные и команды — MQTT с проверкой TLS-сертификатов. При смене заставки зарядка получает адрес ресурса Anker. У проекта нет собственного облачного сервера или аналитики. Авторизация Homey CLI хранится на компьютере отдельно.

## Разработка и обратная связь

```sh
npm ci
npm test
npm run validate
npm run build:check
```

`build:check` создаёт установочный архив в `dist/`, не обращаясь к Homey и ничего не устанавливая. Требуется Node.js 24 или новее на компьютере для установки. Инструменты разработки отделены от зависимостей самого приложения. Помощник установки — утилита проекта, использующая внутренние функции закреплённой версии CLI, а не официальный установщик Athom.

Для ошибок [создайте issue](https://github.com/edsallo/homey-anker-prime/issues): укажите версии приложения, Homey и зарядки, ожидаемое поведение и шаги воспроизведения. Удалите из вложений email, серийные номера, пароли, токены и сертификаты. Можно писать по-русски или по-английски. Установка проверена на macOS; команды для Windows переносимы, но на физическом Windows-компьютере пока не проверялись.

## 0.1.9 — лимиты и отданная энергия

В существующих и новых карточках USB-портов автоматически добавляются:
- «Лимит мощности»: C1 — 5–140 Вт, C2–C4 — 15–100 Вт, шаг 1 Вт; A1 + A2 — общий выбор 0/15/24 Вт.
- «Ручные лимиты»: активны только в пользовательском режиме всей зарядки. Ползунок показывает сохранённый бюджет и при неактивном ручном режиме.
- «Отданная энергия» в Вт·ч и дата последнего сброса в показаниях.
- Отдельная нативная кнопка «Сбросить счётчик» на экране кнопок карточки; сбрасывает только этот порт (для A — сумму пары). История Insights не удаляется.

Изменение лимита включает пользовательский режим. Возврат в AI Power через основную карточку прекращает применение ручных лимитов. Остальные бюджеты и флаги протоколов сохраняются; сумма не может превышать 250 Вт. При нехватке бюджета приложение показывает доступные ватты, не уменьшает другие порты автоматически. Изменение режима может прервать питание на короткое время. Проверены C1: 5/6/10/14/15/16/17/30 Вт; C2–C4 и A пока не проверены под электронной нагрузкой. Нижние значения C1 экспериментальные.

Энергия рассчитывается трапецеидальным интегрированием USB-мощности по свежим измерениям и сохраняется в хранилище устройства Homey. Счёт начинается при обновлении/добавлении устройства, не восстанавливает прошлую энергию. Промежутки между измерениями более 30 секунд, отключение связи и время перезапуска не заполняются; результат может быть неполным. Это выход USB, не расход из розетки и не показания отдельного аппаратного счётчика.

Flow: установить лимит мощности, сбросить счётчик энергии, проверить порог энергии и активность ручных лимитов. Точный числовой ввод лимита доступен в Flow. Новые функции не дублируются в расширенных настройках.

## 0.1.10 — выбор мощности и автоматическое распределение

Ползунок заменён списком целых ватт; действующий сохранённый лимит также виден в показаниях. При превышении общего бюджета 250 Вт выбранный порт получает запрошенное значение. Приложение уменьшает самые большие лимиты других USB-C портов по 1 Вт до устранения превышения, не ниже 15 Вт. Уже меньшие/нулевые бюджеты не увеличиваются. Бюджет USB-A при изменении USB-C сохраняется. При снижении выбранного лимита свободные ватты не распределяются автоматически. Все изменения подтверждаются полным профилем зарядки и отражаются в карточках портов. Это заменяет описанное для 0.1.9 отклонение команды при нехватке бюджета.
